# Navratri: A Journey of Faith & Culture – Survey Analysis Dashboard

## About
An interactive dashboard built by analyzing survey data of 500 people across 22 cities about how they celebrate Navratri.

## What it does
- Survey overview: 500 respondents, 22 cities, average celebration of 5.7 days
- Preferred activities: Garba (33.4%), Dandiya (24.8%), Devi Puja (21.8%)
- Regional analysis: Western region has the highest share (37%)
- Celebration duration: 48% celebrate for 7–9 days; 73% celebrate with family
- Festival spending: Average ₹2,068, Median ₹1,210
- Bar charts, pie chart, and key insights in a single dashboard

## Tech Stack
- Python (data analysis)
- Pandas (data cleaning & analysis)
- NumPy (numerical computations)
- Matplotlib & Seaborn (charts, statistical visualizations)
- Plotly (interactive visualizations)
- Streamlit (dashboard building)
